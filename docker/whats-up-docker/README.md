# What's Up Docker

Monitors local container images and, optionally, one remote Docker socket proxy. Multiple
host-specific watchers from the private deployment are consolidated into generic local and
remote examples.

The Docker socket grants host control. A remote Docker API must be protected by a trusted
network and a restrictive proxy. Registry and SMTP credentials are optional; remove unused
placeholder variables from your local `.env` rather than supplying real values to features
you do not use.
